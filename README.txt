Project Name: AI-Powered Data Insights 
Built an AI-enhanced data solution that combines structured data with LLM-based insights to automatically generate summaries and detect anomalies.

The goal was to help business users quickly understand trends, identify issues, and make decisions without manually analyzing raw data.
Designed a pipeline where cleaned data is processed and analyzed by an LLM to generate human-readable insights alongside traditional dashboards.
Used Python to prepare structured data and integrate with an LLM to generate natural language insights from numerical trends.

Skills: LLM + Python + Business Intelligence Dashboard + Power BI + Pandas
